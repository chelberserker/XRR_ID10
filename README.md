# XRR_ID10_ESRF

This is code for the processing of Surface X-ray Scattering data, obtained on the ID10 beamline at ESRF.

## Content:
1) XRR class, used for the data analysis of X-ray Reflectivity data, obtained with a 2D detector.
2) rebin function, used for rebinning data

## Functionality:
1) Reading h5 files, produced at ID10
2) Region-of-interest based integration of 2D detector data
3) All necessary corrections, including: conversion to qz, errors calculations, footprint correction, rebinning
4) Calculation of reciprocal space maps, obtained during reflectivity experiment
5) Plotting and saving graphs and data
